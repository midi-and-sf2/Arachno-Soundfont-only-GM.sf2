# Arachno Soundfont only GM.sf2 🎹
The perfect Drum Kit / GM SoundFont to complement piano banks (Yamaha C8, Steinway, etc.) that don’t have GM sounds. 
Duplicate piano samples have been removed to save memory and ensure maximum loading speed in OmniMIDI or other.
<br>
<br>
## Features ✨
1. Only **GM sounds/Drum Kits**, no Piano 🚫
2. Ideal to *Yamaha C8, Keppy's Steinway or others soundfonts* without **GM sounds/Drum Kit**.
